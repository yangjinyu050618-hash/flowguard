# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within FlowGuard, please do not open a public issue.
Instead, send an email to yangjinyu050618@gmail.com with details of the vulnerability.

We will acknowledge receipt of your vulnerability report within 48 hours and provide updates on resolution.
